# Personal e-Portfolio

Welcome to my personal e-Portfolio! This website serves as a comprehensive showcase of my academic journey, technical skills, projects, and professional experiences.

## 🚀 Features

- **Modern Interface**: Clean, responsive design with a smooth dark mode toggle.
- **Tech Stack**: Built with React, Vite, and Tailwind CSS.
- **Skill Showcase**: Detailed sections for technical skills, software proficiency, and research interests.
- **Project Highlights**: In-depth looks at key projects including Edelweiss, CS3 System, and various game development experiments.
- **Interactive Elements**: Custom cursors, SVG wave animations, and audio visualizers.
- **Music Integration**: Built-in background music player with toast notifications for song changes.

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) 19
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio**: [React Player](https://www.npmjs.com/package/react-player)
- **Fonts**: [Google Fonts](https://fonts.google.com/) (Lora, Outfit, Anonymous Pro)

## 📂 Project Structure

- `src/`: Contains the main application source code.
  - `components/`: Reusable UI components.
  - `assets/`: Static assets like images, logos, and music.
  - `App.jsx`: Main application component and routing.
  - `index.css`: Global styles and Tailwind configuration.
- `index.html`: Entry point for the application.
- `vite.config.js`: Vite configuration.

## 📁 Assets

All media assets (images, icons, music) are located in the `src/assets/` directory.

## 🎨 Customization

- To change the color scheme, update the CSS variables in `src/index.css`.
- To add or modify projects, edit the `App.jsx` file where the `Projects` section is defined.
- Favicon can be updated by replacing `public/favicon.png`.
